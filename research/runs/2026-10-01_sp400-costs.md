# Run 007 — Does it generalise to the S&P 400, and does it survive trading costs?   [pre-registered 2026-10-01, DAILY]

Follows runs 005/006: removing the 50-EMA and RSI 40-70 gates (H-B) beat BASE and was robust to the history window. Before any live change we need
(1) a different population (S&P 400 mid caps, never used to pick H-B) and (2) trading costs.

## Setup (fixed now)
- Both configs on the LIVE-EQUIVALENT window: Lorentzian fed the trailing 250 bars. No IWM, no VWAP gate, ADX filter ON, vote >= 6, 8% stop, 10-day hold.
  BASE = EMA and RSI gates ON; H-B = EMA and RSI gates OFF. Portfolio rules as run 004 (5%/position, max 20 open, 5 random seeds, no sector cap).
- Universes: S&P 400 (new population) and S&P 500 (rerun with costs). Same split: IS 2022-10-01..2025-09-30, OOS 2025-10-01..2026-09-29.
- Costs = total friction per side (spread + slippage; commissions assumed zero), applied to entry and exit prices:
  base 0.10% per side for the S&P 500, 0.15% per side for the S&P 400; stress 0.25% per side for both. Gross (0%) shown for reference.
- Benchmarks: SPY (both), plus IJH (S&P 400 ETF) for the S&P 400.

## Hypotheses and verdict rules
- H-C (generalises): on the S&P 400 at base cost, H-B beats BASE by the run-005 rule: OOS median total return >= BASE + 2 points, full-period CAGR higher,
  OOS median max drawdown not worse by more than 3 points.
- H-D (survives costs): at base cost, H-B OOS per-trade average >= +0.2% AND PF >= 1.2 on BOTH universes. Beating SPY is reported, not required.
Anything else = "not supported". OOS n < 150 for a variant -> inconclusive.

## Caveats
One OOS year, survivorship (today's index lists), flip exit not modelled, cost level is an assumption (real costs depend on broker and size),
yfinance data, S&P 400 stocks are less liquid (the $5M/day gate still applies).
